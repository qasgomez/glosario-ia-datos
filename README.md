# Glosario vivo de IA y Ciencia de Datos

Un glosario escrito entre todos por el curso. Cada término lo escribe una persona y lo revisa otra antes de publicarse.

**Sitio web:** https://github.com/qasgomez/glosario-ia-datos

## ¿Cómo participo?

1. Elegí un Issue sin dueño en la pestaña *Issues* y asignátelo.
2. Creá una rama desde el Issue.
3. Escribí tu término copiando la estructura de `plantillas/termino.md`.
4. Abrí un Pull Request y completá la plantilla.
5. Pedile la revisión a un compañero.
6. Cuando te aprueben, integrá tu cambio (*Squash and merge*).

Las reglas completas están en [CONTRIBUTING.md](CONTRIBUTING.md).

## Estructura del repositorio

- `terminos/`: un archivo por término.
- `participantes/`: la presentación de cada integrante.
- `plantillas/`: modelos para escribir.
- `index.md`: el índice del glosario.
