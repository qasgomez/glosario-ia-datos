# Dataset

## Definición

Un dataset (conjunto de datos) es una colección de información organizada, generalmente en una tabla donde cada fila es un caso y cada columna es una característica de ese caso. Es la materia prima con la que se entrenan y se prueban los modelos de IA.

## Ejemplo

Una planilla con los datos de 500 pacientes de una clínica, con una fila por paciente y columnas como edad, peso y resultado de un estudio, es un dataset.
